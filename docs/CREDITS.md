# Credits

## Bundled images

SPARK bundles no photographs. The Home screen is type on the ground plus one
card surface; the wordmark is the app's own vector drawing
(`docs/brand/spark-wordmark.svg` → `res/drawable/ic_spark_wordmark.xml`).

## Sources used by the content pipeline

Book, quote and concept text is generated from the public-domain and openly
licensed sources listed in `docs/CONTENT_AUTOMATION.md`. Every card row keeps
its `source_ref` and `license`, so attribution travels with the content.
